# MapScope

MapScope is a lightweight interactive maps website built with plain HTML, CSS, and JavaScript.

## Features

- Interactive world map powered by Leaflet + OpenStreetMap tiles.
- Quick-jump list of featured cities.
- Live latitude/longitude readout on mouse move.
- "Use my location" geolocation button.
- Reset button to return to global map view.

## Run locally

Open `index.html` in your browser.

For best results with local permissions (geolocation), serve it from a local web server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
